Friend Location Visualizer

Visualize where your friends were and when — scrub through time, watch their paths animate, and filter by person. Load your own JSON export or try the built-in sample data.

Expected JSON format

{
  "friends": [
    {
      "name": "Alice",
      "color": "#ff6b6b",          // optional
      "locations": [
        {
          "time": "2024-06-15T09:00:00Z", // ISO 8601 or Unix ms
          "lat": 37.7749,
          "lng": -122.4194,
          "note": "Coffee shop"     // optional
        }
      ]
    }
  ]
}

Also accepts a flat array format where each entry has name, latitude, longitude, and timestamp fields.
